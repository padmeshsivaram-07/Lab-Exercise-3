# Aim

To evaluate the usability of the Swiggy mobile application using Nielsen’s 10 Usability Heuristics, identify usability problems, and suggest design improvements to enhance the user experience.

## Algorithm
# 1.Select the Swiggy mobile application for evaluation.
# 2.Study the main screens and user interactions.
# 3.Apply Nielsen’s 10 usability heuristics.
# 4.Identify usability problems in the existing interface.
# 5.Suggest suitable design improvements.
# 6.Compare the Before and After designs.
# 7.Evaluate how the improvements enhance usability and accessibility.
# 8.Document the final observations and results.
# 9.Output

## Output

| No. | Heuristic Principle | Observation | Proposed Improvement |
|---|---|---|---|
| 1 | Visibility of System Status | Order tracking is displayed in real time. | Keep order status clearly visible. |
| 2 | Match with Real World | Familiar terms like **Cart, Delivery, Offers** are used. | Continue using familiar terminology. |
| 3 | User Control and Freedom | Users can modify cart items and cancel orders. | Provide easier undo and cancel options. |
| 4 | Consistency and Standards | Standard food-ordering UI patterns are followed. | Maintain consistent buttons and icons. |
| 5 | Error Prevention | Some actions require multiple steps. | Add confirmation before important actions. |
| 6 | Recognition Rather Than Recall | Food categories and options are visible. | Keep frequently used options easily accessible. |
| 7 | Flexibility and Efficiency | Search and filters help users find restaurants. | Place filters directly below the search bar. |
| 8 | Aesthetic and Minimalist Design | Multiple promotional banners make the screen busy. | Use one featured banner instead of many. |
| 9 | Error Recovery | Error information can be made clearer. | Provide clear error messages and recovery options. |
| 10 | Help and Documentation | Help and support options are available. | Make support options easier to find. |

## Before vs After

| Before | After |
|---|---|
| Many promotional banners | One featured banner |
| Hidden filters | Filters visible below search bar |
| Multiple customization steps | Quick `+ / −` quantity controls |
| Small text | Larger and accessible typography |
| Less visible options | Clear and easily accessible controls |

## Result

The heuristic evaluation of the Swiggy application successfully identified usability issues based on Nielsen’s 10 Usability Heuristics. The proposed improvements simplify navigation, make restaurant discovery faster, reduce unnecessary steps, improve readability, and provide a more efficient, accessible, and user-friendly experience.
